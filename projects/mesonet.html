INTERNSHIP / KENTUCKY MESONET

Helping people make sense of observations.

Weather-data dashboards, Python processing and analysis, and a trained TensorFlow image-recognition model at Kentucky Mesonet.

Role
Application Developer Intern
Tools
Next.js · TypeScript · Python · TensorFlow
Status
September 2022–May 2024

Bring the data into view.

As an Application Developer Intern at Kentucky Mesonet, I developed a weather-data quality-monitoring website using Next.js, React, and TypeScript. The dashboards provided visualizations for inspecting incoming observations.

The work connected application development to a concrete data problem: giving people a useful way to examine measurements and assess their quality.

Support the path to analysis.

I wrote Python scripts to process incoming weather data and support analysis and trend identification. Alongside the dashboard, this gave me experience working with data both before and during its presentation to users.

I also built a Python desktop application for organizing and viewing photographs.

Hands-on machine learning.

I developed and trained a Python/TensorFlow image-recognition model for image analysis, gaining hands-on experience building and training a model alongside the application and data-processing work.

A foundation for the work I do now.

The common thread is making information useful: processing observations, providing a way to inspect them, and building tools around the people working with the results.

That carries into my current work on application workflows, data integrity, and connected business systems.
