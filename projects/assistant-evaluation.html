How does it handle failures?

Previous question: Tell me about the website chatbot

The portfolio assistant validates citation numbers against supplied sources and checks Setwise answers for active-development status; these checks do not prove every claim is true. Provider failures, invalid or incomplete answers, timeouts, and API version mismatches fall back to local portfolio evidence. The interface supports stopping answers and clearing recent-question context. Provider credentials stay server-side; request validation and per-instance throttles bound requests. Automated tests cover API behavior, follow-up resolution, citations, and browser fallback flows. [1]
