Small game. Real engineering.+

The car runs on a fixed 60-step simulation, independent of the display’s refresh rate. Steering, lateral grip, and the handbrake create the drift; ordered checkpoints keep lap timing honest.

Your fastest valid two-lap run can become a ghost. It is stored only in this browser, with a track and physics version so an old replay won’t race a changed circuit. If browser storage is unavailable, you can still play.

The three-minute run limit bounds recording size. Pause or leave the tab and the clock stops. No account, server, or score upload.
